# 版本变更记录

## V3.7　2026-10-01

- 新增版权水印与数字签名模块（`js/watermark.js`）：界面淡水印、元信息署名、不可见字符指纹、运行时溯源信息与验签接口 `Watermark.verify()`。
- 全部 JS/CSS 文件加入签名注释头；数据文件加入作者与签名元数据。
- 源码、数据与软件界面植入「羽织梦，以梦化羽；所织皆梦，所梦皆羽」签名，标记编号 `YZM-OPC-2026`。

## V3.6　2026-09-11

- 登录页、启动页与首页横幅品牌图标更换为放大镜图标，并按主体外接圆自动居中与放大，修正偏小偏下的显示问题。

## V3.5　2026-09-11

- 新增单文件网页版：把 CSS、脚本、数据与图片全部内联，支持双击离线运行。
- 网页版补充本地存储兜底与内嵌数据拦截，保证在 `file://` 环境下可用。

## V3.4　2026-09-10

- 8 大风险类图标更换为新版风险符号图标，并统一背景色调（内源风险淡蓝、外源风险淡橙）。
- 新增 APK 展示下载页与软件介绍演讲稿。

## V3.2　2026-09-06

- 智能体默认接入 DeepSeek 大模型，保留本地知识库降级模式。
- 新增记忆层（`js/memory.js`）：问卷结果沉淀为动态档案、记忆条目与本地经验池，并在智能体对话中自动调用。
- 知识库纳入质性调查《编码后的发现汇总》，新增 9 条问答与结构化研究发现。

## V3.0　2026-09-01

- 界面重构为单页应用（首页、风险库、测评、AI 助手、报告、我的）。
- 风险体系重构为 2 大风险域、8 大风险类、24 项具体风险，问卷与风险一一对应。
- 报告输出综合风险分、四档等级、风险类型、雷达图、治理行动清单与复盘提醒。
