## 三、模块职责与调用关系

```text
用户界面层
  app.js（页面路由：首页 / 风险库 / 测评 / AI 助手 / 报告 / 我的）
  └─ report.js（报告渲染、雷达图、历史对比）
        │
领域逻辑层
  questionnaire.js（量表计分 → 风险分 → 四级判定 → 风险画像）
  agent.js（智能体对话：DeepSeek 在线 / 本地知识库降级 / 治理建议生成）
        │
数据与记忆层
  memory.js（问卷 → 动态档案 + 记忆条目 + 对话备忘 + 经验池）
  storage.js（本地存储）＋ auth.js（本地账号）
        │
内容与版权层
  data/*.json（风险知识库、问卷、问答库）
  watermark.js（版权水印、零宽指纹、溯源信息、验签）
```

调用顺序：`index.html` 载入 → `storage/auth` 初始化 → `watermark` 植入版权标记 → `questionnaire/agent` 加载数据 → `app` 渲染界面。用户完成问卷时，`questionnaire.complete()` 生成报告并调用 `memory.recordAssessment()` 沉淀记忆；与智能体对话时，`agent` 将记忆上下文注入系统提示词。

## 四、数据结构

| 数据文件 | 关键字段 | 用途 |
|---|---|---|
| risk-types.json | categories（风险域）、risks（风险类）、specificRisks（具体风险 + 访谈原话 + 出处）、symptoms、causes、consequences、recommendations、governance（立即 / 7 日 / 中长期）、externalSupport、agentFollowup | 风险知识库与治理策略 |
| initial-questionnaire.json | meta（量表定义）、basicInfo（6 题）、questions（24 题，含 riskId / categoryId 映射） | 问卷采集与计分 |
| knowledge-base.json | faq（21 条问答）、researchFindings（3 大调查发现）、greetings | 智能体本地回答与对话开场 |

## 六、检查发现

| 序号 | 发现 | 处理意见 |
|---|---|---|
| 1 | `report.js` 中保留 `assets/characters/` 路径拼接 | 属**双运行环境设计**：安卓包按相对路径读取图片；单文件网页版由构建脚本替换为内嵌 base64。保留无误。 |
| 2 | 深度、来源、后果等字段为中文长文本 | 已确认无敏感个人信息；访谈原话仅保留受访者代称（如 SoloNest 宁宁）。 |
| 3 | 数据文件含作者与签名元数据（author / motto / _mark） | 版权归属需要，予以保留。 |
| 4 | 未发现 TODO / FIXME、密钥泄露、调试输出残留 | 无需处理。 |
