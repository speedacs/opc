# OPC 风险筛查（OPC Risk Screening）

面向人工智能时代一人公司（OPC）创业者的风险筛查与治理工具。软件把风险识别、评估、分级、预警、诊断、干预与复盘的专业方法，转化为在手机上独立完成的轻量流程，回答三个问题：风险在哪里、严重到什么程度、下一步做什么。

## 功能特性

- **风险测评**：6 题基础信息 + 24 题量表，覆盖 2 大风险域、8 大风险类、24 项具体风险。
- **风险画像**：0-100 综合风险分、四档等级（低风险 / 关注 / 预警 / 高风险）、风险类型、TOP 风险与雷达图。
- **治理建议**：按「立即处理 / 7 日内 / 中长期」输出行动清单，并推荐外部专业支持。
- **AI 智能体**：接入大模型进行个性化追问与诊断；未配置接口时使用内置知识库离线回答。
- **记忆与复盘**：每次测评沉淀为动态风险档案与记忆条目，复测自动对比风险变化。
- **风险知识库**：8 大风险类知识、21 条问答与质性调查发现。
- **双端同源**：安卓应用与单文件网页版共用同一套代码。

## 技术架构

```text
交互层  app.js（页面路由）＋ report.js（报告与图表）
领域层  questionnaire.js（计分与分级）＋ agent.js（智能体对话）
数据层  memory.js（记忆沉淀）＋ storage.js（本地存储）＋ auth.js（本地账号）
内容层  data/*.json（风险知识库、问卷、问答库）
版权层  watermark.js（版权水印、零散指纹、溯源信息）
```

设计原则：风险评分、等级与类型由结构化算法计算，大模型仅承担语言解析与建议生成，保证判断可复现、可追溯。

## 快速开始

### 方式一：直接用浏览器打开

用任意静态服务器打开 `src/index.html` 即可：

```bash
cd src
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

### 方式二：打包成单文件网页版

```bash
python tools/build_single_html.py src out/OPC-risk-screening.html
```

生成的 HTML 把 CSS、脚本、数据与图片全部内联，双击即可离线运行。

### 方式三：打包成安卓应用

本项目前端可直接用于 Capacitor 工程：将 `src/` 作为 `webDir` 指向的目录，配置应用名与包名后执行 `npx cap sync android` 并用 Android Studio 或 Gradle 打包 APK。

## 自定义数据

| 文件 | 内容 |
|---|---|
| `src/data/risk-types.json` | 风险域、风险类、具体风险、症状、成因、后果、治理建议、行动清单 |
| `src/data/initial-questionnaire.json` | 基础信息题与量表题（含与风险的映射关系） |
| `src/data/knowledge-base.json` | 智能体本地问答库与调查发现 |
| `src/assets/characters/` | 风险图标与助手形象（可替换同名文件） |

修改数据后重新生成 `src/js/data-bundled.js`（离线内嵌数据）即可生效。
